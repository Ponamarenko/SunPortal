# SunPortal

Android-додаток для моніторингу сонячної станції: схема потоків енергії (PV → інвертор →
батарея / мережа → дім), погода, блекаути, прогноз виробітку, тарифи та TOU.

Стиль інтерфейсу — як у «Svitgrid» (Flutter): темна тема, моноширинний шрифт JetBrains Mono,
градієнтні картки `#131A24 → #0A0D12`, анімації Lottie з оригінальних ассетів svitgrid.

## Версія

`versionCode = 33`, `versionName = "1.0.32"` — актуальний стан `main`.

У 1.0.31 повернуто візуальний шар версії **1.0.17** (схема потоків `FlowScheme.kt`,
`Components.kt`, `ui/theme/Color.kt`, `Type.kt`, `LottieArt.kt`): після 1.0.17 схему
переробляли під Svitgrid (3 PV-колонки, UPS-бейдж, велика батарея, вигнуті лінії) —
саме ці зміни прибрані. 1.0.32 — та сама збірка з актуального `main` (без змін в UI),
з оновленими документами.

## Джерело даних

Додаток працює з власним шлюзом `deye_gateway.py` (тека `deye-integration/`).
Адреса за замовчуванням — `http://ha4a.pp.ua:8080/`, змінюється в
`Налаштування → Сервер` (IP/порт).

| Ендпоінт | Що віддає |
|---|---|
| `api/live/raw` | поточні показники: `p_sun`, стринги, `p_load`, `batt_soc`, `p_grid`, напруга/струм АКБ, температури |
| `api/?action=history&period=day` | історія точками (крок 10 хв) для графіків |
| `api/?action=blackout` | графік відключень, адреса, черга |
| `weather_read.php` | погода по годинах |
| `forecast_read.php` | прогноз виробітку на 3 дні |
| `tou_read.php` | слоти тарифу TOU |

Інвертор: **Deye SUN-12K-SG02LP1-EU-AM3** (мануал — `Deye_SUN7_12K_SG02LP1_EU_AM3_Manual_UA.pdf`).

## Источники погоды

`Налаштування → Джерело погоди`:

| Режим | Поведение |
|---|---|
| **Авто** | сначала сервер (`weather_read.php`), при его недоступности — Open-Meteo |
| **Сервер** | только сервер SunPortal |
| **Open-Meteo** | только Open-Meteo (https://api.open-meteo.com), без ключа |

Для Open-Meteo нужны координаты объекта (широта/долгота) — вводятся там же.
Ответ Open-Meteo переводится в общий формат `WeatherData` (`model/OpenMeteoMapper.kt`),
поэтому карточка погоды и схема потоков работают одинаково для обоих источников.
Погода обновляется автоматически каждые 10 минут; источник показан бейджем в карточке.

## Офлайн-режим

Последний успешный ответ сервера сохраняется в DataStore (`cache_live_json`).
Если сервер недоступен (или нет сети), HOME показывает последние известные значения
вместо ошибки и помечает шапку «⚠️ Немає зв'язку — останні дані».
Опрос сервера продолжается каждые 5 с, как только связь вернётся — данные обновятся сами.
HOME и «Огляд» используют один общий `LiveViewModel`, поэтому запрос к серверу — один,
а не два (раньше каждый экран опрашивал сервер сам).
Пока приложение свёрнуто (экран выключен), опрос замедляется до 1 раза в минуту —
`MainScreen.LivePollingLifecycle` следит за жизненным циклом Activity.

## TOU (розклад тарифа) и резерв АКБ

Экран TOU показывает слоты, которые сервер отдаёт в `tou_read.php`.
Записи расписания сервер **не поддерживает** (проверено: `tou_write.php` / `api/?action=set` — 404),
поэтому кнопка «Записати» недоступна, а **пресеты заполняют таблицу локально**:

| Пресет | Что делает |
|---|---|
| **Blackout** | в слотах отключений — не заряжать (берем резерв), ночью — заряд 12 кВт от сети до 100% |
| **Від прогнозу** | дневные слоты — мощность зарядки из почасового прогноза выработки, ночные — от сети |
| **Ніч** | заряд 12 кВт от сети, SOC 100% |
| **День** | заряд 12 кВт от генератора, SOC 80% |

В окне **«АКБ»** добавлена оценка резерва: остаток ёмкости ÷ текущая нагрузка
(«≈ 118 год» / «≈ 4.9 дня»), плюс накопленные заряд и разряд (`battery_charge_total`,
`battery_discharge_total`).

## Уведомления

Канал **«Сповіщення станції»** (`ui/notifications/Notifier.kt`) — приходят сообщения:

- ⚡ **Відключення світла** — отключение уже началось (станция перешла на аккумулятор);
- 🔌 **Скоро відключення** — до начала отключения меньше часа (`17:00–18:00`);
- 🔋 **Акумулятор заряджено** — SOC пересёк 95% (заряд завершён);
- ⚠️ **Низький заряд АКБ** — во время отключения SOC упал до 20% и ниже.

Отключения берутся с сервера (`api/?action=blackout`), статусы считает `BlackoutViewModel`
(обновление раз в минуту). Событие уведомляется один раз — статус запоминается в
`rememberSaveable`, поэтому повторно при смене вкладок не приходит.
SOC берётся из live-данных (`LiveViewModel`, общий опрос раз в 5 с).

На Android 13+ нужно разрешение `POST_NOTIFICATIONS` — запрашивается при первом запуске
(`MainActivity.NotificationPermissionEffect`). Колокольчик в шапке HOME открывает
историю оповещений (последние 20 событий в памяти приложения), кнопка «Налаштування»
в этом диалоге — системные настройки уведомлений.

## Схема потоков (в стиле Svitgrid)

Общая схема `ui/common/FlowScheme.kt` (HOME и «Огляд») повторяет экран Svitgrid:

```
   PV1          PV2          PV3        ← 3 колонки: подпись, мощность, панель, индикатор
    │            │            │             (Lottie solar, зелёная точка = выработка идёт)
 ═══╪════════════╪════════════╪═══        ← PV-шина: линия с узлами-квадратами
                │                            ← поток в инвертор (бегущие точки + стрелка)
  [БАТАРЕЯ]    [ИНВЕРТОР]    [СЕТЬ]      ← узлы: Lottie + значение + подпись
                │
             [ДОМ]                         ← дом с погодной анимацией (солнце/дождь/снег)
```

- PV-колонки стоят над батареей / инвертором / сетью; общая выработка — над рядом («☀ 1,2 кВт»).
- Направление потоков по знаку мощности: батарея и сеть — в инвертор или из него,
  инвертор → дом. Бегущие точки ускоряются с ростом мощности.
- Линии передачи тонкие (1.2 dp в HOME / 0.8 dp в «Огляде»), точки и стрелки мелкие;
  концы линий идут от края иконки к краю иконки, поэтому стрелки направления видны.
- Иконки крупные: батарея/сеть 88 dp, инвертор 84 dp, дом до 104 dp (ужимается на низких
  экранах), панель PV 52 dp, иконка типа домовладения 28 dp.
- Дом на схеме — Lottie-вариант по погоде и времени суток (вытянуты из Svitgrid):
  солнце / дождь / снег / ветер (при ветре ≥ 8 м/с) + ночные версии.
- Тип домовладения (иконка Svitgrid) выбирается в `Налаштування → Тип домоволодіння`
  и показывается в узле «Дом» рядом с подписью «Споживання».

## Тип домовладіння

`Налаштування → Тип домоволодіння` — 8 изометрических иконок Svitgrid
(квартира, будинок, дача, ферма, теплица, магазин, солнечная станция, мастерня).
Выбор сохраняется в DataStore (`household_type`) и подхватывается общей схемой потоков.
