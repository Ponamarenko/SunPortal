# SunPortal

Android-додаток для моніторингу сонячної станції: схема потоків енергії (PV → інвертор →
батарея / мережа → дім), погода, блекаути, прогноз виробітку, тарифи та TOU.

Стиль інтерфейсу — як у «Svitgrid» (Flutter): темна тема, моноширинний шрифт JetBrains Mono,
градієнтні картки `#131A24 → #0A0D12`, анімації Lottie з оригінальних ассетів svitgrid.

## Источники погоды

`Налаштування → Джерело погоди`:

| Режим | Поведение |
|---|---|
| **Авто** | сначала сервер (`weather_read.php`), при его недоступности — Open-Meteo |
| **Сервер** | только сервер SunPortal |
| **Open-Meteo** | только Open-Meteo (https://api.open-meteo.com), без ключа |

Для Open-Meteo нужны координаты объекта (широта/долгота) — вводятся там же.
Ответ Open-Meteo переводится в общий формат `WeatherData` (`model/OpenMeteoMapper.kt`),
поэтому карточка погоды и схема потоков работают одинаково для обоих источников.
Погода обновляется автоматически каждые 10 минут; источник показан бейджем в карточке.

## Офлайн-режим

Последний успешный ответ сервера сохраняется в DataStore (`cache_live_json`).
Если сервер недоступен (или нет сети), HOME показывает последние известные значения
вместо ошибки и помечает шапку «⚠️ Немає зв'язку — останні дані».
Опрос сервера продолжается каждые 5 с, как только связь вернётся — данные обновятся сами.
HOME и «Огляд» используют один общий `LiveViewModel`, поэтому запрос к серверу — один,
а не два (раньше каждый экран опрашивал сервер сам).

## TOU (розклад тарифа) и резерв АКБ

Экран TOU показывает слоты, которые сервер отдаёт в `tou_read.php`.
Записи расписания сервер **не поддерживает** (проверено: `tou_write.php` / `api/?action=set` — 404),
поэтому кнопка «Записати» недоступна, а **пресеты заполняют таблицу локально**:

| Пресет | Что делает |
|---|---|
| **Blackout** | в слотах отключений — не заряжать (берем резерв), ночью — заряд 12 кВт от сети до 100% |
| **Від прогнозу** | дневные слоты — мощность зарядки из почасового прогноза выработки, ночные — от сети |
| **Ніч** | заряд 12 кВт от сети, SOC 100% |
| **День** | заряд 12 кВт от генератора, SOC 80% |

В окне **«АКБ»** добавлена оценка резерва: остаток ёмкости ÷ текущая нагрузка
(«≈ 118 год» / «≈ 4.9 дня»), плюс накопленные заряд и разряд (`battery_charge_total`,
`battery_discharge_total`).

## Уведомления

Канал **«Сповіщення станції»** (`ui/notifications/Notifier.kt`) — приходят сообщения:

- ⚡ **Відключення світла** — отключение уже началось (станция перешла на аккумулятор);
- 🔌 **Скоро відключення** — до начала отключения меньше часа (`17:00–18:00`).

Отключения берутся с сервера (`api/?action=blackout`), статусы считает `BlackoutViewModel`
(обновление раз в минуту). Событие уведомляется один раз — статус запоминается в
`rememberSaveable`, поэтому повторно при смене вкладок не приходит.

На Android 13+ нужно разрешение `POST_NOTIFICATIONS` — запрашивается при первом запуске
(`MainActivity.NotificationPermissionEffect`). Колокольчик в шапке HOME открывает
настройки уведомлений приложения.
