# Svitgrid

Сборник свежих версий программы **Svitgrid** — место для загрузки и хранения исходников/сборок.

Здесь пользователь загружает свежие версии приложения Svitgrid, чтобы из них можно было брать различные значки и идеи для UI.

## Структура

- `Svitgrid/` — папка с свежими версиями программы Svitgrid
