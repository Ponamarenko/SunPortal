## В роботі / заплановано

### 1) Автооновлення з GitHub Releases
Мета: перевіряти наявність нової версії та пропонувати завантаження/встановлення APK прямо з застосунку.

- [ ] **Перевірка версії** — запит `GET https://api.github.com/repos/Ponamarenko/SunPortal/releases/latest`, порівняння `tag_name` (`vX.Y.Z`) та `versionCode` з `BuildConfig`
- [ ] **Сповіщення про оновлення** — діалог «Доступна нова версія vX.Y.Z. Оновити?» з кнопками «Пізніше» / «Завантажити та встановити»
- [ ] **Завантаження APK** — зберігати в `context.getExternalCacheDir()/updates/` через `OkHttp` або `DownloadManager`
- [ ] **Встановлення APK** — `FileProvider` + `Intent.ACTION_VIEW` або `PackageInstaller`. Потрібен `android.permission.REQUEST_INSTALL_PACKAGES`
- [ ] **UI** — пункт «Перевірити оновлення» у екрані «Про застосунок» (`AboutScreen`)
- [ ] **Обробка дозволів** — підказка «Дозволити встановлення з цього джерела» при першому запуску
- [ ] **Мінімальний варіант (швидкий)** — поки що лише «Відкрити реліз на GitHub» якщо не встигнемо з авто-встановленням

**Технічні деталі:**
- `AndroidManifest.xml`: `REQUEST_INSTALL_PACKAGES`, `FileProvider` з `res/xml/file_paths.xml`
- `network_security_config` — не потрібен (GitHub HTTPS)
- Працює з наявними релізами в `Ponamarenko/SunPortal`
- Не використовує Google Play In-App Updates (застосунок поширюється через GitHub)

## Принципи
- **Тільки код** — на телефоні немає можливості збірки, тож всі зміни перевіряються через коміти та збірку на ПК/CI
- **GitHub-first** — APK розповсюджується через GitHub Releases
- **Мінімум залежностей** — по можливості без сторонніх бібліотек для оновлень
- **Зворотня сумісність** — не ламати роботу на наявних версіях
